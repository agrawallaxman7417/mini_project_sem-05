# EventYatra — Sunburn Goa 2026

A responsive event-details page for EventYatra, built with plain HTML, CSS and vanilla JavaScript.

## Structure

```text
eventyatra-sunburn-goa-2026/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   └── images/
│       └── README.md
└── README.md
```

## Tech

- HTML5
- CSS3
- Vanilla JavaScript
- Plus Jakarta Sans (Google Fonts)

## Features

- Responsive desktop/tablet/mobile layout
- Mobile navigation drawer
- Sticky desktop ticket panel
- Mobile booking CTA
- Event ticket cards
- Gallery lightbox with keyboard navigation
- Smooth in-page navigation
- Accessible focus states

## Run locally

Open `index.html` directly in a browser, or use VS Code Live Server.

## GitHub

Upload the complete `eventyatra-sunburn-goa-2026` folder to your repository. Keep the folder structure unchanged so the relative CSS and JS links continue to work.

> The current event photography is referenced from the image URLs already present in the supplied design. The `assets/images` folder is kept ready if you later want to replace those remote images with local files.
